# 《商户服务协议》

**版本**：V1.0
**生效日期**：____ 年 __ 月 __ 日
**适用主体**：在本平台开店经营的全部商户

---

## 第一条 平台性质与服务范围

1.1 本平台为「商户营销服务工具」，性质为**纯技术信息中介**，向商户提供以下技术服务：
- 商品信息发布与管理
- 营销活动配置工具（推 N 反 1 / 邀请有礼 / 促销让利池等）
- 订单信息流转
- 推广关系数据记录与展示

1.2 **平台不参与商品交易**，不沉淀资金，不进行商品担保，不对商户经营行为及结果承担任何责任。商户系平台内独立经营者，依法独立享有权利、承担义务。

1.3 平台与商户之间为技术服务合同关系，**不构成代理、合伙、雇佣或共同经营**关系。

---

## 第二条 商户合规承诺

2.1 商户作为商品经营主体，对其经营的商品及营销活动承担**全部独立责任**，包括：
- 商品的真实性、安全性、合法性
- 商品的价格合理性与定价依据
- 商品描述、宣传文案的真实性
- 营销规则的合规性
- 资金兑付义务

2.2 商户郑重承诺，所有上架商品满足：
- 具有真实使用价值（非道具型商品）
- 价格按同品类市场价合理范围定价（不高于同品类市场价 3 倍）
- 商品描述真实，不夸大、不虚假宣传
- 不通过商品销售变相收取"加盟费""门槛费""会员费"

2.3 商户在营销活动配置和宣传中，**严禁**使用以下词汇及表达：
- "投资"、"回本"、"躺赚"、"暴富"、"日入过万"
- "推广资格"、"激活资格"、"购买激活"
- "团队"、"团队收益"、"团队佣金"
- "上线"、"下线"、"层级"、"极差"
- "拉人头"、"拉新提成"
- 任何暗示多层级返佣或保证收益的表达

2.4 商户营销规则的「**最终解释权**」**归商户所有**。平台仅提供配置工具，不审查、不背书、不对结果担责。消费者就营销规则的任何争议，应直接向商户主张，**商户无条件承担处理义务及相应法律责任**。

---

## 第三条 禁止行为

3.1 商户**严禁**通过平台工具进行以下行为（违反即立即下架 + 冻结结算 + 追究法律责任）：

（一）**多层级团队计酬**：以下线销售业绩为依据计算上线报酬，超过 1 层的返佣机制；
（二）**入门费/资格费**：收取或变相收取"加盟费""门槛费""保证金""会员费"以取得发展资格；
（三）**道具化商品**：销售明显高于市场价 3 倍以上的商品作为推广门票；
（四）**虚假宣传**：在商品名称、描述、营销话术中出现"投资""资格""加盟""回本""躺赚"等违规词汇；
（五）**任何形式的传销 / 资金盘 / 非法集资 / 庞氏骗局**；
（六）违反《中华人民共和国电子商务法》《禁止传销条例》《刑法》第二百二十四条之一等法律法规的任何行为。

3.2 平台对上述行为采取的措施包括但不限于：
- 商品下架
- 营销规则强制冻结
- 商户账户冻结
- 提现申请拒绝
- 向工商监管机关举报
- 配合司法机关调查

3.3 平台保留对违规行为的最终认定权。

---

## 第四条 资金责任划分

4.1 **资金来源**：商户营销让利奖励的全部资金，由商户从自身经营收入中划拨，**与本平台账户无关**。

4.2 **资金通道**：平台仅作为技术通道辅助资金流转记录，**不沉淀任何商户营销资金**。

4.3 **资金兑付**：商户应保证营销让利预算充足，及时支付推广用户的提现申请。

4.4 **逾期赔付**：因商户资金不足导致推广用户无法提现的：
- 由商户全额承担兑付义务及违约责任
- 平台**不承担任何先行赔付义务**
- 平台不为商户的任何资金兑付提供担保

---

## 第五条 法律责任划分

5.1 商户配置的营销规则、商品定价、宣传内容违反法律法规（包括但不限于《禁止传销条例》《刑法》第 224 条之一组织、领导传销活动罪、《反不正当竞争法》《广告法》《电子商务法》等），由**商户独立承担全部法律责任**，包括但不限于：

（一）**行政处罚**：罚款 / 没收违法所得 / 吊销执照 / 列入黑名单；
（二）**民事赔偿**：消费者投诉 / 退款 / 损失赔偿 / 集体诉讼；
（三）**刑事追究**：涉及刑事责任的，由商户法定代表人 / 实际控制人 / 实际经营者承担。

5.2 **商户对平台的赔偿责任**：

商户被监管机关认定违法、被消费者投诉、被司法机关追究的，应主动配合监管调查，**不得将平台列为共同被告 / 共同当事人**。

若因商户违规行为导致平台被监管调查 / 被起诉 / 被罚款 / 被舆论攻击的，商户应**全额赔偿平台**：
- 监管罚款金额（如有）
- 律师费、诉讼费、保全费
- 公关费用、商誉损失
- 因此导致的间接经济损失
- 平台为应对调查投入的人力成本

5.3 平台保留依据本协议对违规商户提起**连带追偿诉讼**的权利。

## 第六条 商户合规承诺的法律效力

6.1 商户签署本协议（含电子签署、勾选确认）即视为对全部条款的**完全接受**。

6.2 商户**法定代表人 / 实际控制人**需在本协议附加签署《合规个人承诺书》，承诺对商户经营行为承担**个人连带责任**。

6.3 本协议承诺一经签署，**不可撤销、不可抗辩、不可减损**。商户嗣后对本协议条款的任何异议、抗辩、撤销请求均不予支持。

6.4 商户应定期（建议每季度）审视自身经营行为，及时整改可能违规的事项。商户主动整改并书面通知平台的，可减轻相应平台赔偿责任。

## 第七条 协议变更与终止

7.1 平台保留依据法律法规变更、监管要求调整、业务发展需要修订本协议的权利。

7.2 平台修订本协议的，提前 7 个工作日通过平台公告方式通知商户。商户在通知期内未提出书面异议并继续使用平台服务的，视为接受变更后的协议。

7.3 商户严重违规的，平台有权**立即终止**本协议并冻结相关账户，无需事先通知。
