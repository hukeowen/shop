05 / 老客邀请

REFERRAL

让老客户帮你
邀请新顾客。

单层推广激励，只奖励直接邀请人。基于真实成交结算、合规归本 — 老板放心做。

单层邀请 · 仅 1 级

老客邀请奖励，自动到账

老客户分享商品 / 店铺，扫码下单成交即按比例发放推广积分到邀请人。只奖励直接邀请人，不发展层级，严守合规边界。

  • 商户自定义推广积分比例（1% – 30%）
  • 仅 1 级关系，依据真实订单结算
  • 积分冻结期可设，防止刷单退款
  • 提现线上审核，流水全留痕
推广激励 · 按 GMV

推广激励，按 GMV 归本

商户可设立 1 名推广伙伴，伙伴每达成 GMV 目标可领取约定的推广激励（不与人数挂钩，仅与成交销量挂钩），让老板回本节奏可控。

  • 固定档位 / 阶梯比例，老板自定
  • 结算依据：成交 GMV，不计人数
  • 合同 / 协议模板内置，直接用
  • 所有结算可导出，备查备税
